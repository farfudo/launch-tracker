# Ride Together

O **Ride Together** é outra app do autor do NextRocketLaunch, ainda em desenvolvimento. Ajuda a organizar passeios em grupo e a acompanhar os participantes durante a sessão.

[Abrir a versão web do Ride Together](https://ride-together-app.vercel.app/)

## O que faz

- Permite criar um passeio e convidar amigos através de um código ou ligação.
- Mostra a localização partilhada dos participantes durante o passeio.
- Permite definir pontos de encontro e consultar a distância até ao próximo.
- Apresenta alertas quando alguém se afasta do grupo ou deixa de enviar localização.
- Inclui os avisos rápidos **Parei**, **Avaria** e **Esperem**.
- Quando o organizador termina o passeio, a partilha termina e as posições são apagadas.

A versão web funciona no navegador; a página precisa de permanecer aberta para continuar a partilhar a localização. O projeto também tem uma app nativa em desenvolvimento.
